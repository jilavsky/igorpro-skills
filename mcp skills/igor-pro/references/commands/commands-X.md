# Igor Pro commands starting with X

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **x** - The x function returns the scaled row index for the current point of the destination wave in a wave assignment statement. - `references/manual/commands/x.md`
- **x2pnt** - The x2pnt function returns the integer point number on the wave whose X value is closest to x1. - `references/manual/commands/x2pnt.md`
- **xcsr** - The xcsr function returns the X value of the point which the named cursor (A through J) is on in the top (or named) graph. - `references/manual/commands/xcsr.md`
- **XLLoadWave** - The XLLoadWave operation loads data from the named Excel.xls,.xlsx or.xlsm file into waves. - `references/manual/commands/xlloadwave.md`
- **XWaveName** - The XWaveName function returns a string containing the name of the wave supplying the X coordinates for the named trace in the named graph window or subwindow. - `references/manual/commands/xwavename.md`
- **XWaveRefFromTrace** - The XWaveRefFromTrace function returns a wave reference to the wave supplying the X coordinates against which the named trace is displayed in the named graph… - `references/manual/commands/xwavereffromtrace.md`
