# Igor Pro commands starting with Q

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **q** - The q function returns the current column index of the destination wave when used in a multidimensional wave assignment statement. - `references/manual/commands/q.md`
- **qcsr** - The qcsr function can be used with cursors on images or waterfall plots to return the column number. - `references/manual/commands/qcsr.md`
- **Quit** - The Quit operation quits Igor Pro. - `references/manual/commands/quit.md`
