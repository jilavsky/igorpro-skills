# Igor Pro commands starting with Z

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **z** - The z function returns the Z value for the current layer of the destination wave when used in a multidimensional wave assignment statement. - `references/manual/commands/z.md`
- **zcsr** - The zcsr function returns a Z value when the specified cursor is on a contour, image or waterfall plot. Otherwise, it returns NaN. - `references/manual/commands/zcsr.md`
- **ZernikeR** - The ZernikeR function returns the Zernike radial polynomials of degree n that contains no power of r that is less than m. - `references/manual/commands/zerniker.md`
- **zeta** - The zeta function returns the Hurwitz Zeta function for real or complex arguments a and b. - `references/manual/commands/zeta.md`
