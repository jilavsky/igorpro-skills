# Igor Pro commands starting with K

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **KillBackground** - The KillBackground operation kills the unnamed background task. KillBackground works only with the unnamed background task. - `references/manual/commands/killbackground.md`
- **KillControl** - The KillControl operation kills the named control in the top or specified graph or panel window or subwindow. - `references/manual/commands/killcontrol.md`
- **KillDataFolder** - The KillDataFolder operation kills the specified data folder and everything in it including other data folders. - `references/manual/commands/killdatafolder.md`
- **KillFIFO** - The KillFIFO operation discards the named FIFO. FIFOs are used for data acquisition. - `references/manual/commands/killfifo.md`
- **KillFreeAxis** - The KillFreeAxis operation removes a free axis specified by axisName from a graph window or subwindow. - `references/manual/commands/killfreeaxis.md`
- **KillPath** - The KillPath operation removes a path from the list of symbolic paths. KillPath is a newer name for the RemovePath operation. - `references/manual/commands/killpath.md`
- **KillPICTs** - The KillPICTs operation removes one or more named pictures from the current Igor experiment. - `references/manual/commands/killpicts.md`
- **KillStrings** - The KillStrings operation discards the named global strings. - `references/manual/commands/killstrings.md`
- **KillVariables** - The KillVariables operation discards the named global numeric variables. - `references/manual/commands/killvariables.md`
- **KillWaves** - The KillWaves operation destroys the named waves. The memory the waves occupied becomes available for other uses. - `references/manual/commands/killwaves.md`
- **KillWindow** - The KillWindow operation kills or closes a specified window or subwindow without saving a recreation macro. - `references/manual/commands/killwindow.md`
- **KMeans** - KMeans analyzes the clustering of data in populationWave using an iterative algorithm. - `references/manual/commands/kmeans.md`
