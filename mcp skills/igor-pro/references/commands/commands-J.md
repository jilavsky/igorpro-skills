# Igor Pro commands starting with J

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **j** - The j function returns the loop index of the 2nd innermost iterate loop in a macro. Not to be used in a function. - `references/manual/commands/j.md`
- **JacobiCn** - The JacobiCn function returns the Jacobian elliptic function cn(x,k) for real x and modulus k with. - `references/manual/commands/jacobicn.md`
- **JacobiSn** - The JacobiSn function returns the Jacobian elliptic function sn(x,k) for real x and modulus k with. - `references/manual/commands/jacobisn.md`
- **JCAMPLoadWave** - The JCAMPLoadWave operation loads data from the named JCAMP-DX file into waves. - `references/manual/commands/jcamploadwave.md`
- **jlim** - The jlim function returns the ending loop count for the 2nd inner most iterate loop in a macro. Not to be used in a function. - `references/manual/commands/jlim.md`
- **JointHistogram** - The JointHistogram computes 2D, 3D and 4D joint histograms of data provided in the input waves. - `references/manual/commands/jointhistogram.md`
- **JulianToDate** - The JulianToDate function returns a date string containing the day, month, and year. The input julianDay is truncated to an integer. - `references/manual/commands/juliantodate.md`
