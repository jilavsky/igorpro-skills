# Igor Pro commands starting with L

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **Label** - The Label operation labels the named axis with labelStr. axisName is the name of an existing axis in the top graph. - `references/manual/commands/label.md`
- **laguerre** - The laguerre function returns the Laguerre polynomial of degree n (positive integer) and argument x. The polynomials satisfy the recurrence relation. - `references/manual/commands/laguerre.md`
- **laguerreA** - The LaguerreA function returns the associated Laguerre polynomial of degree n (positive integer), index k (nonnegative integer) and argument x. - `references/manual/commands/laguerrea.md`
- **laguerreGauss** - The LaguerreGauss function returns the normalized product of the associated Laguerre polynomials and a Gaussian. - `references/manual/commands/laguerregauss.md`
- **LambertW** - The LambertW function returns the complex value of Lambert's W function for complex z and integer index branch. The function can be defined through its inverse. - `references/manual/commands/lambertw.md`
- **Layout** - The Layout operation creates a page layout. The Layout operation is antiquated and cannot be used in user-defined functions. - `references/manual/commands/layout.md`
- **LayoutInfo** - The LayoutInfo function returns a string containing a semicolon-separated list of keywords and values that describe an object in the active page of a page… - `references/manual/commands/layoutinfo.md`
- **LayoutPageAction** - The LayoutPageAction operation adds, deletes, reorders, or adjusts the sizes of layout pages. - `references/manual/commands/layoutpageaction.md`
- **LayoutSlideShow** - The LayoutSlideShow operation starts, stops, or modifies a slideshow that displays the pages of a page layout. - `references/manual/commands/layoutslideshow.md`
- **leftx** - The leftx function returns the X value of point 0 (the first point) of the named 1D wave. The leftx function is not multidimensional aware. - `references/manual/commands/leftx.md`
- **Legend** - The Legend operation puts a legend on a graph or page layout. legendStr contains the text that is printed in the legend. - `references/manual/commands/legend.md`
- **legendreA** - The legendreA function returns the associated Legendre polynomial: $$ \displaystyle P_{n}^{m}(x) $$. - `references/manual/commands/legendrea.md`
- **limit** - The limit function returns num, limited to the range from low to high. - `references/manual/commands/limit.md`
- **LinearFeedbackShiftRegister** - The LinearFeedbackShiftRegister operation implements a, well, linear feedback shift register, or LFSR. - `references/manual/commands/linearfeedbackshiftregister.md`
- **ListBox** - The ListBox operation creates or modifies the named control that displays, in the target window, a list from which the user can select any number of items. - `references/manual/commands/listbox.md`
- **ListMatch** - The ListMatch function returns each list item in listStr that matches matchStr. - `references/manual/commands/listmatch.md`
- **ListToTextWave** - The ListToTextWave function returns a free text wave containing the individual list items in listStr. - `references/manual/commands/listtotextwave.md`
- **ListToWaveRefWave** - The ListToWaveRefWave function returns a free wave containing a wave reference for each entry in stringList that corresponds to an existing wave. - `references/manual/commands/listtowaverefwave.md`
- **ln** - The ln function returns the natural logarithm of num, -INF if num is 0, or NaN if num is less than 0. - `references/manual/commands/ln.md`
- **LoadData** - The LoadData operation loads data from the named file or folder. "Data" means Igor waves, numeric and string variables and data folders containing them. - `references/manual/commands/loaddata.md`
- **LoadPackagePreferences** - The LoadPackagePreferences operation loads preference data previously stored on disk by the SavePackagePreferences operation. - `references/manual/commands/loadpackagepreferences.md`
- **LoadPICT** - The LoadPICT operation loads a picture from a file or from the Clipboard into Igor. - `references/manual/commands/loadpict.md`
- **LoadWave** - The LoadWave operation loads data from the named Igor binary, Igor text, delimited text, fixed field text, or general text file into waves. - `references/manual/commands/loadwave.md`
- **Loess** - The Loess operation smooths srcWaveName using locally-weighted regression smoothing. - `references/manual/commands/loess.md`
- **log** - The log function returns the log base 10 of num. It returns -INF if num is 0, and returns NaN if num is less than 0. - `references/manual/commands/log.md`
- **logNormalNoise** - The logNormalNoise function returns a pseudo-random value from the lognormal distribution function whose probability distribution function is. - `references/manual/commands/lognormalnoise.md`
- **LombPeriodogram** - The LombPeriodogram is used in spectral analysis of signal amplitudes specified by srcAmpWave which are sampled at possibly random sampling times given by… - `references/manual/commands/lombperiodogram.md`
- **lorentzianNoise** - The function returns a pseudo-random value from a Lorentzian distribution. - `references/manual/commands/lorentziannoise.md`
- **LowerStr** - The LowerStr function returns a string expression identical to str except that all upper case ASCII characters are converted to lower case. - `references/manual/commands/lowerstr.md`
