# Igor Pro commands starting with E

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **e** - The e function returns the base of the natural logarithm system (2.7182818...). - `references/manual/commands/e.md`
- **EdgeStats** - The EdgeStats operation produces simple statistics on a region of a wave that is expected to contain a single edge. - `references/manual/commands/edgestats.md`
- **Edit** - The Edit operation creates a table window or subwindow containing the specified columns. - `references/manual/commands/edit.md`
- **ei** - The ei function returns the value of the exponential integral Ei (x): $$ \displaystyle E i(x)=P \int_{-\infty}^{x} \frac{e^{t}}{t} d t \quad(x>0), $$. - `references/manual/commands/ei.md`
- **EllipticE** - The EllipticE function returns the complete elliptic integral of the second kind. - `references/manual/commands/elliptice.md`
- **EllipticK** - The EllipticK function returns the complete elliptic integral of the first kind. - `references/manual/commands/elliptick.md`
- **enoise** - The enoise function returns a random value drawn from a uniform distribution having a range of [-num, num). - `references/manual/commands/enoise.md`
- **EqualWaves** - The EqualWaves function compares waveA to waveB. Each wave can be of any data type. It returns 1 for equality and zero otherwise. - `references/manual/commands/equalwaves.md`
- **erf** - The erf function returns the error function of num. $$ \displaystyle \operatorname{erf}(x)=\frac{2}{\sqrt{\pi}} \int_{0}^{x} e^{-t^{2}} d t. - `references/manual/commands/erf.md`
- **erfc** - The erfc function returns the complementary error function of num (erfc(x) = 1 - erf(x)). - `references/manual/commands/erfc.md`
- **erfcw** - The erfcw is a complex form of the error function defined by $$ \displaystyle \operatorname{erfcw}(z)=\exp \left[-z^{2}\right] \operatorname{erfc}(-i z), $$. - `references/manual/commands/erfcw.md`
- **erfcx** - The erfcx function returns the scaled complementary error function of num. - `references/manual/commands/erfcx.md`
- **ErrorBars** - The ErrorBars operation adds or removes error bars to or from the named trace in the specified graph and modifies error bar settings. - `references/manual/commands/errorbars.md`
- **EstimatePeakSizes** - The EstimatePeakSizes operation estimates the amplitudes and widths of peaks whose estimated centers are given. - `references/manual/commands/estimatepeaksizes.md`
- **Execute** - The Execute operation executes the contents of cmdStr as if it had been typed in the command line. - `references/manual/commands/execute.md`
- **ExecuteScriptText** - The ExecuteScriptText operation passes your text for compilation and execution to the Windows command line. - `references/manual/commands/executescripttext.md`
- **exists** - The exists function returns a number which indicates if objNameStr contains the name of an Igor object, function or operation. - `references/manual/commands/exists.md`
- **exp** - The exp function returns enum. In complex expressions, num is complex, and exp(num) returns a complex value. - `references/manual/commands/exp.md`
- **ExperimentInfo** - The ExperimentInfo operation returns information about the current Igor experiment. - `references/manual/commands/experimentinfo.md`
- **ExperimentModified** - The ExperimentModified operation gets and optionally sets the modified (save) state of the current experiment. - `references/manual/commands/experimentmodified.md`
- **expInt** - The expInt function returns the value of the exponential integral En (x). - `references/manual/commands/expint.md`
- **ExpIntegralE1** - The ExpIntegralE1(z) function returns the exponential integral of z. If z is real, a real value is returned. If z is complex then a complex value is returned. - `references/manual/commands/expintegrale1.md`

- **ExportGizmo** - The ExportGizmo operation is obsolete but is still supported for partial backward compatibility. - `references/manual/commands/exportgizmo.md`
