# Igor Pro commands starting with U

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **UniqueName** - The UniqueName function returns the concatenation of baseName and a number such that the result is not in conflict with any other object name. - `references/manual/commands/uniquename.md`
- **UnPadString** - The UnPadString function undoes the action of PadString. It returns a string identical to str except that trailing bytes of padValue have been removed. - `references/manual/commands/unpadstring.md`
- **UnsetEnvironmentVariable** - The UnsetEnvironmentVariable function deletes the variable named varName from the environment of Igor's process, if it exists. - `references/manual/commands/unsetenvironmentvariable.md`
- **Unwrap** - The Unwrap operation scans through each named wave trying to undo the effect of a modulus operation. - `references/manual/commands/unwrap.md`
- **UnzipFile** - The UnzipFile operation unzips a file and saves the contents of the file in the specified output directory. - `references/manual/commands/unzipfile.md`
- **UpperStr** - The UpperStr function returns a string expression identical to str except that all lower case ASCII characters are converted to upper case. - `references/manual/commands/upperstr.md`
- **URLDecode** - The URLDecode function returns a percent-decoded copy of the percent-encoded string inputStr. - `references/manual/commands/urldecode.md`
- **URLEncode** - The URLEncode function returns a percent-encoded copy of inputStr. Percent-encoding is useful when encoding the query part of a URL or when the URL contains… - `references/manual/commands/urlencode.md`
- **URLRequest** - The URLRequest operation connects to a URL using the specified method and optionally stores the response from the server. - `references/manual/commands/urlrequest.md`
- **UTF8CharLength** - The UTF8CharLength function returns the number of bytes in the UTF-8 character ("code point") that begins at the startByte offset in the string expression str. - `references/manual/commands/utf8charlength.md`
