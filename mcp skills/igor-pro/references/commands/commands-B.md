# Igor Pro commands starting with B

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **BackgroundInfo** - The BackgroundInfo operation returns information about the current unnamed background task. - `references/manual/commands/backgroundinfo.md`
- **Base64Decode** - The Base64Decode function returns a decoded copy of the Base64-encoded string inputStr. The contents of inputStr are not checked for validity. - `references/manual/commands/base64decode.md`
- **Base64Encode** - The Base64Encode function returns a copy of inputStr encoded as Base64. - `references/manual/commands/base64encode.md`
- **Beep** - The Beep operation plays the system beep sound. - `references/manual/commands/beep.md`
- **Besseli** - The Besseli function returns the modified Bessel function of the first kind, In (z), of ordern and argument z. - `references/manual/commands/besseli.md`
- **Besselj** - The Besselj function returns the Bessel function of the first kind, Jn (z), of ordern and argument z. - `references/manual/commands/besselj.md`
- **Besselk** - The Besselk function returns the modified Bessel function of the second kind, Kn (z), of ordern and argument z. - `references/manual/commands/besselk.md`
- **Bessely** - The Bessely function returns the Bessel function of the second kind, Yn (z), of ordern and argument z. - `references/manual/commands/bessely.md`
- **bessI** - Obsolete -- use Besseli. The bessI function returns the modified Bessel function of the first kind, In (x), of ordern and argument x. - `references/manual/commands/bessi.md`
- **bessJ** - Obsolete -- use Besselj. The bessJ function returns the Bessel function of the first kind, Jn (x), of order n and argument x. - `references/manual/commands/bessj.md`
- **bessK** - Obsolete -- use Besselk. The bessK function returns the modified Bessel function of the second kind, Kn (x), of order n and argument x. - `references/manual/commands/bessk.md`
- **bessY** - Obsolete -- use Bessely. The bessY function returns the Bessel function of the second kind, Yn (x), of order n and argument x. - `references/manual/commands/bessy.md`
- **beta** - The beta function is defined for real or complex arguments as $$ \displaystyle B(a, b)=\frac{\Gamma(a) \Gamma(b)}{\Gamma(a+b)}, $$. - `references/manual/commands/beta.md`
- **betai** - The betai function returns the regularized incomplete beta function Ix (a, b). - `references/manual/commands/betai.md`
- **BezierToPolygon** - The BezierToPolygon operation creates an XY pair of waves approximating the Bezier curves described by bezXWave and bezYWave. - `references/manual/commands/beziertopolygon.md`
- **BinarySearch** - The BinarySearch function performs a binary search of waveName for the value val. - `references/manual/commands/binarysearch.md`
- **BinarySearchInterp** - The BinarySearchInterp function performs a binary interpolated search of the named wave for the value val. - `references/manual/commands/binarysearchinterp.md`
- **binomial** - The binomial function returns the ratio: $$ \displaystyle \frac{n!}{k!(n-k)!} $$. - `references/manual/commands/binomial.md`
- **binomialln** - The binomialln function returns the natural log of the binomial coefficient for a and b. - `references/manual/commands/binomialln.md`
- **binomialNoise** - The binomialNoise function returns a pseudo-random value from the binomial distribution. - `references/manual/commands/binomialnoise.md`
- **BoundingBall** - The BoundingBall operation calculates a bounding circle or the bounding sphere for a set of scatter points. - `references/manual/commands/boundingball.md`
- **BoxSmooth** - The BoxSmooth operation replaces smoothedWave with a smoothed copy of srcWave. The waves must both exist. - `references/manual/commands/boxsmooth.md`
- **BrowseURL** - The BrowseURL operation opens the web browser or FTP browser on your computer and asks it to display a particular web page or to connect to an FTP server. - `references/manual/commands/browseurl.md`
- **BuildMenu** - The BuildMenu operation rebuilds the user-defined menu items in the specified menu the next time the user clicks in the menu bar. - `references/manual/commands/buildmenu.md`
- **Button** - The Button operation creates or modifies the named button control in the target window. - `references/manual/commands/button.md`
