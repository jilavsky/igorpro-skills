# Igor Pro commands starting with O

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **Open** - The Open operation can, depending on the flags passed to it: Open an existing file to read data from (/R flag without /D). - `references/manual/commands/open.md`
- **OpenHelp** - The OpenHelp operation opens the specified help file. The OpenHelp operation was added in Igor Pro 7.00. - `references/manual/commands/openhelp.md`
- **OpenNotebook** - The OpenNotebook operation opens a file for reading or writing as an Igor notebook. - `references/manual/commands/opennotebook.md`
- **OpenProc** - The OpenProc operation opens a file as an Igor procedure file. This operation is used automatically by Igor to open procedure files when you open an Igor… - `references/manual/commands/openproc.md`
- **OperationList** - The OperationList function returns a string containing a list of internal (built-in) or external operation names names corresponding to matchstr. - `references/manual/commands/operationlist.md`
- **Optimize** - The Optimize operation determines extrema (minima or maxima) of a specified nonlinear function. - `references/manual/commands/optimize.md`
