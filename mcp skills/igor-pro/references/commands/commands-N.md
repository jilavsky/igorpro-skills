# Igor Pro commands starting with N

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **NameOfWave** - The NameOfWave function returns a string containing the name of the specified wave. - `references/manual/commands/nameofwave.md`
- **NaN** - The NaN function returns the "Not a Number" value, according to the IEEE standards. - `references/manual/commands/nan.md`
- **NeuralNetworkRun** - This operation is deprecated. The NeuralNetworkRun operation uses the interconnection weights generated by NeuralNetworkTrain, and saved in the waves… - `references/manual/commands/neuralnetworkrun.md`
- **NeuralNetworkTrain** - This operation is deprecated. The NeuralNetworkTrain operation trains a three-layer neural network. - `references/manual/commands/neuralnetworktrain.md`
- **NewCamera** - The NewCamera operation creates a new camera window to display live video from supported hardware cameras. - `references/manual/commands/newcamera.md`
- **NewDataFolder** - The NewDataFolder operation creates a new data folder of the given name. - `references/manual/commands/newdatafolder.md`
- **NewFIFO** - The NewFIFO operation creates a new FIFO. Useless until channel info is added with NewFIFOChan. - `references/manual/commands/newfifo.md`
- **NewFIFOChan** - The NewFIFOChan operation creates a new channel for the named FIFO. channelName must be unique for the specified FIFO. - `references/manual/commands/newfifochan.md`
- **NewFreeAxis** - The NewFreeAxis operation creates a new free axis with no controlling wave. - `references/manual/commands/newfreeaxis.md`
- **NewFreeDataFolder** - The NewFreeDataFolder function creates a free data folder and then returns its data folder reference. - `references/manual/commands/newfreedatafolder.md`
- **NewFreeWave** - The NewFreeWave function creates a free 1D wave of the given type and number of points and then returns its wave reference. - `references/manual/commands/newfreewave.md`
- **NewGizmo** - The NewGizmo operation creates a new Gizmo display window. The NewGizmo operation will fail if the graphics hardware or drivers are incompatible with Gizmo. - `references/manual/commands/newgizmo.md`
- **NewImage** - The NewImage operation creates a new image graph much like "Display;AppendImage matrix ", except that the graph is prepared using a style more appropriate for… - `references/manual/commands/newimage.md`
- **NewLayout** - The NewLayout operation creates a page layout. Unlike the Layout operation, NewLayout can be used in user-defined functions. - `references/manual/commands/newlayout.md`
- **NewMovie** - The NewMovie operation opens a movie file in preparation for adding frames. - `references/manual/commands/newmovie.md`
- **NewNotebook** - The NewNotebook operation creates a new notebook document. the optional titleStr is a string containing the title of the notebook window. - `references/manual/commands/newnotebook.md`
- **NewPanel** - The NewPanel operation creates a control panel window or subwindow, which may contain Igor controls and drawing objects. - `references/manual/commands/newpanel.md`
- **NewPath** - The NewPath operation creates a new symbolic path name that can be used as a shortcut to refer to a folder on disk. - `references/manual/commands/newpath.md`
- **NewWaterFall** - The NewWaterfall operation creates a new waterfall plot window or subwindow using each column in the 2D matrix wave as a waterfall trace. - `references/manual/commands/newwaterfall.md`
- **norm** - The norm function evaluates the norm of srcWave. It returns: $$ \displaystyle \sqrt{\sum a b s(w[i])^{2}} $$. - `references/manual/commands/norm.md`
- **NormalizeUnicode** - The NormalizeUnicode function normalizes the UTF-8-encoded text in sourceTextStr using the specified normalization form. - `references/manual/commands/normalizeunicode.md`
- **Note** - The Note operation appends str to the wave note for the named wave. str is a string expression. - `references/manual/commands/note_operation.md`
- **note** - The note function returns a string containing the note associated with the specified wave. - `references/manual/commands/note_function.md`
- **Notebook** - The Notebook operation sets various properties of the named notebook window. Notebook also inserts text and graphics. See Notebooks for general information. - `references/manual/commands/notebook.md`
- **NotebookAction** - The NotebookAction operation creates or modifies an "action" in a notebook. A notebook action is an object that executes commands when clicked. - `references/manual/commands/notebookaction.md`
- **num2char** - The num2char function returns a string containing a character. The options parameter was added in Igor Pro 7.00 and defaults to 0. - `references/manual/commands/num2char.md`
- **num2istr** - The num2istr function returns a string representing the number num after rounding to the nearest integer. - `references/manual/commands/num2istr.md`
- **num2str** - The num2str function returns a string representing the number num. The optional formatStr parameter was added in Igor Pro 9.00. - `references/manual/commands/num2str.md`
- **NumberByKey** - The NumberByKey function returns a numeric value extracted from kwListStr based on the specified key contained in keyStr. - `references/manual/commands/numberbykey.md`
- **numpnts** - The numpnts function returns the total number of data points in the named wave. - `references/manual/commands/numpnts.md`
- **numtype** - The numtype function returns a number which indicates what kind of value num contains. - `references/manual/commands/numtype.md`
- **NumVarOrDefault** - The NumVarOrDefault function checks to see if the pathStr points to a numeric variable. If the numeric variable exists, NumVarOrDefault returns its value. - `references/manual/commands/numvarordefault.md`
- **NVAR_Exists** - The NVAR_Exists function returns one if specified NVAR reference is valid or zero if not. It can be used only in user-defined functions. - `references/manual/commands/nvar_exists.md`
