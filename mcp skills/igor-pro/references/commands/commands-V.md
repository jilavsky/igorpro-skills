# Igor Pro commands starting with V

Each line: **Name** - one-line summary - local page to read with read_file for full syntax, flags, outputs, examples.

- **ValDisplay** - The ValDisplay operation creates or modifies the named control that displays a numeric value in the target window. The appearance of the control varies. - `references/manual/commands/valdisplay.md`
- **Variable** - The Variable operation creates real or complex variables and gives them the specified name. - `references/manual/commands/variable.md`
- **VariableList** - The VariableList function returns a string containing a list of the names of global variables selected based on the matchStr and variableTypeCode parameters. - `references/manual/commands/variablelist.md`
- **Variance** - Returns the variance of the real-valued inWave. The function ignores NaN and INF values in inWave. - `references/manual/commands/variance.md`
- **vcsr** - The vcsr function returns the Y (vertical) value of the point which the specified cursor (A through J) is attached to in the top (or named) graph. - `references/manual/commands/vcsr.md`
- **VoigtFunc** - VoigtFunc computes the Voigt function using an approximation that has an accuracy of, as described by the author, "typically at least 13 significant digits". - `references/manual/commands/voigtfunc.md`
- **VoigtPeak** - The VoigtPeak function returns a value from a Voigt peak shape defined by coefficients in wave w at location x. It was added in Igor Pro 8.00. - `references/manual/commands/voigtpeak.md`
