## <strong>fresnelSin</strong> (<em>x</em>) {#fresnelsin}

</div>

The fresnelSin function returns the Fresnel sine function *S*(*x*).

$$
\displaystyle S(x)=\int_{0}^{x} \sin \left(\frac{\pi}{2} t^{2}\right) d t .
$$
