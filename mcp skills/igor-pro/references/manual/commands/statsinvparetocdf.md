## <strong>StatsInvParetoCDF</strong> (<em>cdf</em>, <em>a</em>, <em>c</em>) {#statsinvparetocdf}

</div>

The StatsInvParetoCDF function returns the inverse of the Pareto cumulative distribution function

$$
\displaystyle x=\frac{a}{(1-c d f)^{(1 / c)}}
$$
