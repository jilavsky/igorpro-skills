## <strong>StatsPoissonCDF</strong> (<em>x</em>, λ) {#statspoissoncdf}

</div>

The StatsPoissonCDF function returns the Poisson cumulative distribution function.

$$
\displaystyle F(x ; \lambda)=\sum_{i=0}^{x} \frac{\exp (-\lambda) \lambda^{i}}{i!}, \quad x=0,1,2 \ldots
$$
