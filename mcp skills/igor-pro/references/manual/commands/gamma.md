<div className="command-signature">

## <strong>gamma</strong> (<em>num</em>) {#gamma}

</div>

The gammma function returns the value of the gamma function of *num*. If *num* is complex, it returns a complex result. Note that the return value for *num* close to negative integers is NaN, not +/-Inf.
