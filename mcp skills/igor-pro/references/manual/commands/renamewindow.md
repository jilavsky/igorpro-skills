<div className="command-signature">

## <strong>RenameWindow</strong>  <em>oldName</em>, <em>newName</em> {#renamewindow}

</div>

The RenameWindow operation renames an existing window or subwindow from *oldName* to *newName*.

### *Parameters* {#parameters}
*oldName* is the name of an existing window or subwindow.

When identifying a subwindow with *oldName*, see [Subwindow Syntax](/igorpro/graphing/making-figures/subwindows.md#subwindow-syntax) for details on forming the window hierarchy.
