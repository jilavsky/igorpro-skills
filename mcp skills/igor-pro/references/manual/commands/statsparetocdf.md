## <strong>StatsParetoCDF</strong> (<em>x</em>, <em>a</em>, <em>c</em>) {#statsparetocdf}

</div>

The StatsParetoCDF function returns the Pareto cumulative distribution function.

$$
\displaystyle F(x ; a, c)=1-\left(\frac{a}{x}\right)^{c}.
$$
