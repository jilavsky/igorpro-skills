<div className="command-signature">

## <strong>x2pnt</strong> (<em>waveName</em>, <em>x1</em>) {#x2pnt}

</div>

The x2pnt function returns the integer point number on the wave whose X value is closest to *x1*.

For higher dimensions, use [ScaleToIndex](/igorpro/commands/scaletoindex.md).

For an explanation of X scaling of 1D waves, see [The Waveform Model of Data](/igorpro/igor-basics/waves.md#the-waveform-model-of-data).
