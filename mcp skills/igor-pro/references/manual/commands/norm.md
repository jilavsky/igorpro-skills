## <strong>norm</strong> (<em>srcWave</em>) {#norm}

</div>

The norm function evaluates the norm of *srcWave*. It returns:

$$
\displaystyle \sqrt{\sum a b s(w[i])^{2}}
$$

This function does not support text waves.
