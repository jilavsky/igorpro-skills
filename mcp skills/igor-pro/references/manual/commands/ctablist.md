## <strong>CTabList</strong> () {#ctablist}

</div>

The CTabList function returns a semicolon-separated list of the names of Igor's built-in color tables. This is useful for creating pop-up menus in control panels.

Color tables available through Igor Pro 4:

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| Grays | Rainbow | YellowHot | BlueHot | BlueRedGreen |
| RedWhiteBlue | PlanetEarth | Terrain |  |  |
