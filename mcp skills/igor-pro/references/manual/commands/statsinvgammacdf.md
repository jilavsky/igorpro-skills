<div className="command-signature">

## <strong>StatsInvGammaCDF</strong> (<em>cdf</em>, µ, σ, γ) {#statsinvgammacdf}

</div>

Returns the inverse  of the gamma cumulative distribution function (CDF).  There is no closed form expression for the inverse gamma CDF; it is evaluated numerically.
