<div className="command-signature">

## <strong>cd</strong>  <em>dataFolderSpec</em> {#cd}

</div>

The cd operation sets the current data folder to the specified data folder. It is identical to the longer-named [SetDataFolder](/igorpro/commands/setdatafolder.md) operation.

cd is named after the UNIX "change directory" command.
