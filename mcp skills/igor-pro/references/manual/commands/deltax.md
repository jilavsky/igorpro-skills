<div className="command-signature">

## <strong>deltax</strong> (<em>waveName</em>) {#deltax}

</div>

The deltax function returns the named wave's Δx value.

### *Details* {#details}
This is equal to the difference of the X value of point 1 minus the X value of point 0.

### *See Also* {#see-also}
[leftx](/igorpro/commands/leftx.md), [rightx](/igorpro/commands/rightx.md)

When working with multidimensional waves, use the [DimDelta](/igorpro/commands/dimdelta.md) function.

For an explanation of waves and wave scaling, see [The Waveform Model of Data](/igorpro/igor-basics/waves.md#the-waveform-model-of-data).
