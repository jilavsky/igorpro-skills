<div className="command-signature">

## <strong>Quit</strong>  [/N/Y] {#quit}

</div>

The Quit operation quits Igor Pro.

### *Flags* {#flags}

|  |  |
| --- | --- |
| <span class="table-cell-nowrap">/N</span> | Quits without saving changes and without dialog. |
| <span class="table-cell-nowrap">/Y</span> | Saves current experiment before quitting without putting up dialog unless current experiment is "Untitled". |
