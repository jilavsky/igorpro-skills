## <strong>StatsInvWeibullCDF</strong> (<em>cdf</em>, µ, σ, γ) {#statsinvweibullcdf}

</div>

The StatsInvWeibullCDF function returns the inverse of the Weibull cumulative distribution function

$$
\displaystyle x=\mu+\sigma[-\ln (1-c d f)]^{1 / \gamma}.
$$
