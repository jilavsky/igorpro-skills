## <strong>StatsChiPDF</strong> (<em>x</em>, <em>n</em>) {#statschipdf}

</div>

The StatsChiPDF function returns the chi-squared probability distribution function for the specified value and degrees of freedom as

$$
f(x ; n)=\frac{\displaystyle \exp \left(-\frac{x}{2}\right) x^{\frac{n}{2}-1}}{\displaystyle 2^{\frac{n}{2}} \Gamma\left(\frac{n}{2}\right)} .
$$
