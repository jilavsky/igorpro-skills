## <strong>fresnelCos</strong> (<em>x</em>) {#fresnelcos}

</div>

The fresnelCos function returns the Fresnel cosine function *C* (*x* ).

$$
\displaystyle C(x)=\int_{0}^{x} \cos \left(\frac{\pi}{2} t^{2}\right) d t .
$$
