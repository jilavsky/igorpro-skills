## <strong>Dilogarithm</strong> (<em>z</em>) {#dilogarithm}

</div>

The Dilogarithm function returns the dilogarithm for real or complex argument z. The dilogarithm is a special case of the polylogarithm defined by

$$
\displaystyle L i_{2}(z)=\sum_{k=1}^{\infty} \frac{z^{k}}{k^{2}} .
$$

The Dilogarithm function was added in Igor Pro 7.00.
