## <strong>max</strong> (<em>num1</em>, <em>num2</em> [, <em>num3</em>, ... <em>num200</em>]) {#max}

</div>

The max function returns the greatest value of *num1*, *num2*, ... *num200* .

If any parameter is NaN, the result is NaN.

### *Details* {#details}
In Igor 7 or later you can pass up to 200 parameters. Previously max was limited to two parameters.
