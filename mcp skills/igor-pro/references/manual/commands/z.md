<div className="command-signature">

## <strong>z</strong> {#z}

</div>

The z function returns the Z value for the current layer of the destination wave when used in a multidimensional wave assignment statement. Z is the scaled layer index while r is the layer index itself.

### *Details* {#details}
Unlike x, outside of a wave assignment statement, z *does not* act like a normal variable.
