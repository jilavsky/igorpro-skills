<div className="command-signature">

## <strong>HideInfo</strong>  [/W=<em>winName</em> ] {#hideinfo}

</div>

The HideInfo operation removes the info panel from a graph if it was previously shown by the ShowInfo operation.

### *Flags* {#flags}

|  |  |
| --- | --- |
| <span class="table-cell-nowrap">/W = *winName*</span> | Hides the info panel in the named window. |
