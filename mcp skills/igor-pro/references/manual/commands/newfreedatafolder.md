## <strong>NewFreeDataFolder</strong> () {#newfreedatafolder}

</div>

The NewFreeDataFolder function creates a free data folder and then returns its data folder reference.

Recommended for advanced programmers only.

### *Details* {#details}
Free data folders are those that are not a part of the normal data folder hierarchy and cannot be located by name.
