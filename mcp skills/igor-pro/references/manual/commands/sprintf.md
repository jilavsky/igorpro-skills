<div className="command-signature">

## <strong>sprintf</strong>  <em>stringName</em>, <em>formatStr</em> [,<em>parameter</em>]... {#sprintf}

</div>

The sprintf operation is the same as printf, except it prints the formatted output to the string variable *stringName* rather than to the history area.

### *Parameters* {#parameters}

|  |  |
| --- | --- |
| *stringName* | Results are "printed" into the named string variable. |
| *formatStr* | See [printf](/igorpro/commands/printf.md). |
| *parameter* | See [printf](/igorpro/commands/printf.md). |

### *See Also* {#see-also}
The [printf](/igorpro/commands/printf.md) operation for complete format and parameter descriptions and [Creating Formatted Text](/igorpro/advanced-topics.md#creating-formatted-text) in the Advanced Topics help file.
