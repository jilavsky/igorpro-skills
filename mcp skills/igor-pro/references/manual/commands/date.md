<div className="command-signature">

## <strong>date</strong> () {#date}

</div>

The date function returns a string containing the current date.

The formatting of dates depends on your operating system and on your preferences entered in the Regional Settings control panel.

### *Examples* {#examples}

```igor
Print date()		// prints   Mon, Mar 15, 1993
```
