<div className="command-signature">

## <strong>GraphNormal</strong>  [/W=<em>winName</em> ] {#graphnormal}

</div>

The GraphNormal operation returns the target or named graph to the normal mode, exiting any drawing mode that it may be in.

You would usually enter normal mode by selecting ShowTools from the Graph menu and clicking the graph tool (the top icon in the tool panel).

### *Flags* {#flags}

|  |  |
| --- | --- |
| <span class="table-cell-nowrap">/W = *winName*</span> | Reverts the named graph window. This must be the first flag specified when used in a Proc or Macro or on the command line. |
