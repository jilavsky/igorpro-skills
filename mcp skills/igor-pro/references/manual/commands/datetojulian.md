## <strong>dateToJulian</strong> (<em>year</em>, <em>month</em>, <em>day</em>) {#datetojulian}

</div>

The dateToJulian function returns the Julian day number for the specified date. The Julian day starts at noon. Use negative number for years BC and positive for AD. To exclude any ambiguity, there is no year zero in this calendar. For general orientation, Julian day 2450000 corresponds to October 9, 1995.
