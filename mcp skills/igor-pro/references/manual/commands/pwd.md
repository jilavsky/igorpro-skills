<div className="command-signature">

## <strong>pwd</strong> {#pwd}

</div>

The pwd operation prints the full path of the current data folder to the history area. It is equivalent to [Print](/igorpro/commands/print.md) [GetDataFolder](/igorpro/commands/getdatafolder.md)(1).

pwd is named after the UNIX "print working directory" command.
