## <strong>StatsCauchyCDF</strong> (<em>x</em>, µ, σ) {#statscauchycdf}

</div>

The StatsCauchyCDF function returns the Cauchy-Lorentz cumulative distribution function

$$
\displaystyle F(x ; \mu, \sigma)=\frac{1}{2}+\frac{1}{\pi} \tan ^{-1}\left(\frac{x-\mu}{\sigma}\right) .
$$
