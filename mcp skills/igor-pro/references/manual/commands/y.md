<div className="command-signature">

## <strong>y</strong> {#y}

</div>

The y function returns the Y value for the current column of the destination wave when used in a multidimensional wave assignment statement. Y is the scaled column index while q is the column index itself.

### *Details* {#details}
Unlike x, outside of a wave assignment statement, y *does not* act like a normal variable.
