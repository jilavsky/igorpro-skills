## <strong>cpowi</strong> (<em>num</em>, <em>ipow</em>) {#cpowi}

</div>

The cpowi function is obsolete as the exponentiation operator ^ handles complex expressions with any combination of real, integer and complex arguments. See [Operator Reference[^]](/igorpro/programming/operators/operator-reference.md#exponent). The cpowi function returns a complex number resulting from raising complex *num* to integer-valued power *ipow*. *ipow* can be positive or negative, but if it is not an integer cpowi returns (NaN, NaN).
