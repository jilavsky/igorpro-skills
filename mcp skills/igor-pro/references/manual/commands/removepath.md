<div className="command-signature">

## <strong>RemovePath</strong>  [/A/Z] <em>pathName</em> {#removepath}

</div>

The RemovePath operation removes a path from the list of symbolic paths. RemovePath is an old name for the [KillPath](/igorpro/commands/killpath.md) operation, which we recommend you use instead.
