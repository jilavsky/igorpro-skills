## RGBAColor {#rgbacolor}

The RGBAColor is the same as RGBColor but with an alpha field to represent translucency.


```igor
Structure RGBAColor
	UInt16 red
	UInt16 green
	UInt16 blue
	UInt16 alpha
EndStructure
```
