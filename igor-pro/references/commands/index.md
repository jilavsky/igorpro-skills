# Igor Pro built-in commands - lookup

**You do not need to read all of this.** Look up one command at a time.

## How to use

1. Preferred: call the `Igor__get_help` tool with the command name (e.g. `WaveStats`). It returns
   the full documentation (syntax, flags, V_ variables, examples).
2. If Igor is not available: find the command's letter below, `read_file`
   `references/commands/commands-<Letter>.md` (small file), then `fetch_url` its link.
3. Or `search_text` for the command name inside `references/commands/`.

The URL pattern is always `https://docs.wavemetrics.com/igorpro/commands/<commandname-lowercase>`,
e.g. https://docs.wavemetrics.com/igorpro/commands/wavestats.

## Problematic Igor rules

- Igor names are case-insensitive for identifiers (variables, waves, functions).
- MatrixOP cannot use p, q, r, s point addressing.
